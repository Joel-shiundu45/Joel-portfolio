## How to host on GitHub Pages

1. Create a new repository on GitHub (e.g. `joel-portfolio` or `username.github.io`).
2. Upload **all three files** in this folder:
   - `index.html`
   - `style.css`
   - `profile.jpg`
3. Go to the repository **Settings → Pages**.
4. Under "Source", select the branch (usually `main`) and folder `/ (root)`.
5. Click Save.
6. After a minute, your site will be live at:  
   `https://yourusername.github.io/repository-name/`  
   (or `https://yourusername.github.io` if you named the repo `yourusername.github.io`)
